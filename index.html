01 · VIBRACIÓ

El so comença quan alguna cosa vibra

Quan piquem un tambor, la seva membrana es mou molt de pressa. El tambor fa vibrar l’aire que té a prop. Després, el moviment passa d’un trosset d’aire al següent fins que ens arriba a l’orella. El so també pot passar per l’aigua i pels materials sòlids, però no pot viatjar si no hi ha cap material.

VibrarVol dir moure’s molt de pressa endavant i enrere.

02 · TO I INTENSITAT

Un so pot ser greu o agut, i també fort o fluix

La freqüència ens diu quantes vibracions hi ha cada segon. Una freqüència baixa fa un so greu; una freqüència alta fa un so agut. La intensitat ens diu si el so és fort o fluix. Un so greu també pot ser fort o fluix, i un so agut també.

03 · DECIBELS

Els decibels indiquen el nivell del so

Els decibels, que escrivim dB, indiquen el nivell sonor: ens diuen com d’intens és un so quan ens arriba. Com més dB, més fort el percebem. No indiquen si el so és greu o agut.

PAS 2 · HO APLIQUEM ALS DECIBELS

Ara tornem als altaveus

En el comptador de dB passa una cosa semblant a la corba logarítmica. Cada vegada que doblem els altaveus iguals, el nivell només puja uns 3 dB.

1 altaveu60 dB

Comencem amb 1 altaveu que fa 60 dB.
Què hem descobert?

Quan els altaveus es doblen, l’energia del so també es dobla. Però el nombre de dB només puja 3 cada vegada. Aquest tipus de comptador s’anomena escala logarítmica: fa servir passos petits per representar canvis molt grans.

Del so al soroll

Quan es converteix en contaminació acústica?

El so forma part de la vida. Parlar, riure o escoltar música no és dolent. Parlem de contaminació acústica quan hi ha soroll excessiu, molest o repetit que dificulta les activitats i afecta el benestar.

L’Ombra i el soroll

L’Ombra no crea directament tot el soroll. Però el món de 2070 té més màquines, trànsit i activitat humana. Reduir aquest soroll també ajuda a construir espais més saludables.

Recorda: no només importa el nombre de dB. També importa quant de temps dura el soroll i com ens afecta.
